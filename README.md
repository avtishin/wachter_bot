# Wachter — alumni-aware модерация чатов РЭШ

Экосистема из двух сервисов на **одном PostgreSQL**:

1. **Бот** (`wachter/`) — Telegram-бот модерации: встречает новичков, узнаёт
   выпускников РЭШ по директории, проводит через кнопочное знакомство (whois),
   кикает непредставившихся.
2. **Дашборд + скрейпер** (`nes_directory/`) — Flask-панель и парсер каталога
   выпускников my.nes.ru: просмотр/поиск выпускников, управление участниками
   чатов, запуск синхронизации.

Один человек = одна **глобальная идентичность** (`tg_identity`), членство —
**по чатам** (`users.chat_id`). Бот лёгкий: событийный (long-polling только по
нужным типам апдейтов), без постоянного сканирования чатов.

## Запуск всего стека (локально, один Docker)

```bash
cd nes_directory
# нужны: ../bot.env (TELEGRAM_TOKEN), creds.env (NES_LOGIN/NES_PASSWORD), .env (APP_PASSWORD)
docker compose up -d --build       # поднимает db + bot + dashboard
docker compose logs -f bot         # логи бота
```

- Дашборд: http://localhost:8000 (Basic Auth: `APP_USER`/`APP_PASSWORD`)
- `db` — Postgres с healthcheck; bot и web ждут его готовности.
- Данные (директория, карточки) переживают пересборку через тома `pgdata`/`out`.

## Бот

### Подключение к чату
1. Добавить бота в группу, выдать права **администратора** (кик + удаление
   сообщений) — без них бот вежливо предупреждает и не работает.
2. В личке боту `/start` — появится список чатов, где вы админ (название чата
   хранится автоматически). `#whois` писать не обязательно.

### Что происходит при входе участника
1. **Знакомая идентичность** (в т.ч. сид из `members.csv`) → приветствие-recap
   (имя из карточки выпускника / ручной правки админа / тг-ник + «о себе»), без кика.
2. **Узнан как выпускник** по Telegram-нику или e-mail из директории →
   приветствие с именем/классом + короткое био, без кика.
3. **Не узнан** → кнопочный whois:
   `категория → [e-mail для выпускника] → программа → год → свободная анкета`.
   - Категории: 🎓 выпускник · 📚 студент · 🤝 друг/сотрудник РЭШ.
   - У каждой категории свой текст анкеты; на каждом шаге кнопка **Назад**.
   - Годы: выпускник — текущий и старше; студент — текущий + будущие
     (BAE +4, остальные +2), без лишнего шага десятилетий.
   - Анкета проверяется: минимальная длина + осмысленность (не «maf27 ....»).
   - Свободный текст сохраняется как «о себе» (`intro`); имя НЕ выдумывается —
     `declared_name` пусто, пока нет привязки к выпускнику или правки админа.
   - По завершении: классификация, запись `tg_identity`, приветствие
     (кликабельное упоминание + класс + текст анкеты + тег `#whois`), удаление
     промежуточных сообщений.
4. Не прошёл анкету → работает таймер: за `notify_delta` минут до кика — whois-
   осознанное напоминание, по истечении `kick_timeout` — бан на `ban_duration`.

### Настройка (в личке, `/start` → чат)
Двухуровневое меню; при выборе показывается текущее значение, «Получить текущие
настройки» приходит несколькими сообщениями:
- **💬 Тексты** — приветствия, 4 анкеты (выпускник/студент/друг/сотрудник),
  запрос e-mail, напоминания, сообщения кика/выхода/бана.
- **⏱ Кик и тайминги** — таймаут кика, напоминание, длительность бана, мин.
  длина анкеты.
- **🛡 Антиспам** — regex-фильтр, «только для новых», сообщение при бане.

Плейсхолдеры: `%USER_MENTION%`, `%TIMEOUT%`, `%MINUTES%`, `%NAME%`, `%CLASS%`,
`#whois`. Имена пользователей экранируются (без markdown-инъекций).

### Команды в чате
| Команда | Доступ | Описание |
|---|---|---|
| `/skip` | admin | Отменить таймер кика (в БД не пишется) |
| `/approve` | admin | Одобрить навсегда (запись в БД) |
| `/whois @username` | все | Показать сохранённое представление |
| `/help` | все | Справка |

## Дашборд (`nes_directory/`)

- **Выпускники** — карточки из директории; поиск на русском (транслитерация
  RU→латиница), фильтры по программе и году, история изменений.
- **Участники чата** — участники, кого бот видел, с **селектором чата** (бот
  может быть в нескольких чатах; один человек — в разных). Фильтры по категории/
  программе/году. Карточка участника: ник в телеграме, привязка к выпускнику,
  смена категории, **правка полей** (имя / о себе / программа / год / email),
  удаление.
- **Синхронизация** — запуск скрейпа (`new`/`full`), расписание (cron, по
  умолчанию вручную), статус и логи ранов.

## Данные

Один Postgres, таблицы:
- `alumni_person` (+ `_history`, `_change_log`), `alumni_program`,
  `alumni_program_year`, `alumni_raw_card`, `alumni_crawl` — директория с полной
  историей версий (владелец схемы — скрейпер).
- `tg_identity` — глобальная идентичность Telegram-пользователя (категория,
  привязка к выпускнику, заявленные данные).
- `chats`, `users` — конфиг чатов и per-chat членство (владелец — бот, Alembic).

## Разработка

```bash
# Бот
pipenv install --dev
pytest -v                          # SQLite, без реального Telegram/Postgres
alembic upgrade head               # миграции схемы бота

# Скрейпер/дашборд
cd nes_directory && pip install -r requirements.txt
pytest -q                          # эфемерный Postgres (testcontainers)
python -c "import alumni_models; alumni_models.init_db()"   # создать схему директории
```

## Деплой (Railway, один Postgres)

Оба сервиса делят одну БД. Синк данных — `nes_directory/bootstrap.py` (схема +
ingest + seed `members.csv` + reconcile). Подробно: [DEPLOY.md](DEPLOY.md).
