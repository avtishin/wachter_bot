# Admin Reference

## Начало работы

1. Добавить бота в чат и выдать права **администратора** (кик + удаление
   сообщений) — без них бот предупреждает и не работает.
2. Написать боту в личку `/start` — покажет чаты, где вы админ. Представляться
   через `#whois` **не нужно**.
3. Выбрать чат → настроить через меню.

## Команды

| Команда | Где | Доступ | Описание |
|---|---|---|---|
| `/start` | личка | все | Панель настройки чата (список чатов, где вы админ) |
| `/skip` | чат (ответ) | admin | Отменить таймер кика. В БД **не** пишется — при следующем входе снова анкета |
| `/approve` | чат (ответ) | admin | Одобрить навсегда. Пишется в БД — при следующем входе как знакомый |
| `/whois @username` | чат | все | Показать сохранённое представление (`<user_id>` или ответ тоже) |
| `/help` | любой | все | Справка |

## Как встречают новичка

1. **Знакомый** (есть идентичность) → recap: имя (карточка выпускника / ручная
   правка / тг-ник) + «о себе» + `#whois`, без кика.
2. **Выпускник** (узнан по нику/почте) → приветствие с именем/классом + био.
3. **Новый** → кнопочная анкета: категория → [почта] → программа → год → текст.
   По завершении — приветствие (упоминание + класс + текст) и тег `#whois`.
4. Не прошёл анкету → напоминание, затем кик по таймеру.

## Меню настроек

`/start` → чат → двухуровневое меню. При выборе показывается **текущее
значение**; «Получить текущие настройки» приходит несколькими сообщениями.

**💬 Тексты:** приветствие-знакомство · приветствие выпускника · запрос e-mail ·
анкета выпускника/студента/друга/сотрудника · после знакомства · при перезаходе ·
напоминание закончить анкету · предупреждение перед киком · после кика · при
выходе.

**⏱ Кик и тайминги:**

| Настройка | Описание | По умолчанию |
|---|---|---|
| Таймаут кика | Минут до кика (0 = не кикать) | `30` |
| Напоминание (мин. до кика) | `notify_delta` | `10` |
| Длительность бана | Минут (0 = навсегда) | `1` |
| Мин. длина анкеты | Минимум символов свободного текста | `20` |

**🛡 Антиспам:** regex-фильтр (`%TURN_OFF%` — отключить) · «только для новых»
(`true`/`1`) · сообщение при бане.

## Плейсхолдеры в шаблонах

| Плейсхолдер | Что подставляется |
|---|---|
| `%USER_MENTION%` | Кликабельное упоминание пользователя |
| `%NAME%` | Имя (карточка выпускника / текст анкеты) |
| `%CLASS%` | Класс, напр. `MAE'2019` (у друга/сотрудника отпадает) |
| `%TIMEOUT%` | Таймаут кика в минутах (при 0 клауза убирается) |
| `%MINUTES%` | В напоминании: минут до кика |

Имена пользователей автоматически экранируются (без markdown-инъекций). Отключить
сообщение выхода/кика — значение `false` или `0`.

## Модель имени (важно)

Свободный текст анкеты сохраняется как «о себе» (`intro`). **Имя не выдумывается**:
`declared_name` пусто, пока участник не привязан к выпускнику или имя не задано
вручную на карточке участника в дашборде. Иначе имя = тг-ник.

## Дашборд

Отдельный сервис (`nes_directory/`, Basic Auth): просмотр выпускников (поиск на
русском, фильтры), «Участники чата» (селектор чата, привязка к выпускнику, смена
категории, правка полей), запуск синхронизации директории.
